{# The palette is database-driven, so it has to be written into the document rather than living in the stylesheet. This is the one reason the CSP allows inline styles but not inline scripts. The derived values are here rather than in site.css because each is a mix of two database colours, and CSS cannot mix a value it has not been handed yet. Every mix is expressed against the canvas or the ink, so an owner who changes the paper colour gets a set of tints that still belong to it. Included by both the public layout and the portal layout, because a client who signs in should land in the same brand they just left. #}
