{{ ico('help') }} What the file needs

A header row, then one lead per row. Only name plus either an email or a phone is required - a row without a way to reach someone is skipped rather than imported as a dead record.

Column names it recognises

  • name · also full name, contact
  • email
  • phone · also mobile, number
  • whatsapp · falls back to the phone
  • company, city
  • service · also service_interest
  • budget
  • value · also quote_value
  • message · also notes

Anything else in the file is ignored. Header names are matched case-insensitively.

Duplicates

A row whose email, phone or WhatsApp number already exists is skipped, not merged and not added again. Duplicates are what make a CRM stop being trusted, so the import refuses to create them and tells you how many it passed over.

Getting a template

Export your leads and use that file's header row - the export and the import speak the same column names.
